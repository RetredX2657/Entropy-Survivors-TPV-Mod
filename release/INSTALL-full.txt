FrogCam {VERSION} - third-person camera for Entropy Survivors
https://github.com/RetredX2657/Entropy-Survivors-TPV-Mod

This download includes UE4SS (the mod loader FrogCam runs on), already set up.
If you already use UE4SS with other mods, get the "mod-only" download instead.


INSTALL
-------
1. In Steam, right-click Entropy Survivors > Manage > Browse local files.
2. Open the folder  EntropySurvivors\Binaries\Win64
   (the one that contains EntropySurvivors-Win64-Shipping.exe).
3. Copy everything from this zip into that folder.
   Afterwards  dwmapi.dll  and the  ue4ss  folder sit right next to
   EntropySurvivors-Win64-Shipping.exe.
4. Start the game. A hint at the top of the screen shows the keys.


CONTROLS
--------
  Mouse            look and aim (the frog shoots where the camera points)
  WASD             move, relative to the camera
  F5               third person on / off (back to the original top-down view)
  F6               camera distance: near (almost first person) / mid / far
  Hold Left Ctrl   free mouse pointer, for clicking hub pop-ups
                   such as "Change Class - Open Menu"

Settings can be changed in game from the console (the ~ key):
  frogcam              list all settings
  frogcam fov 85       change one (saved automatically)
  frogcam reset        back to defaults


GOOD TO KNOW
------------
- Single-player only: FrogCam switches itself off in co-op.
- Looking up stops a little above level; the game can only aim when the
  camera is above the frog's gun.
- Mouse and keyboard only for now (no controller support yet).


UNINSTALL
---------
Delete  dwmapi.dll  and the  ue4ss  folder from the Win64 folder.
To remove only FrogCam but keep UE4SS: delete  ue4ss\Mods\FrogCam.
